# Tabletop Characters (project site)

The public page for [TTRPGCharacterCreation](https://github.com/Sakayxshi/TTRPGCharacterCreation), a character creator for The Witcher TRPG, Vampire: The Masquerade (5th ed.) and Cyberpunk 2020, built for the [MariaDB student projects](https://mariadb.org/bachelor_hackathon_2026-09/), area 5: authentication and access control.

- `index.html`, `site.css`, `img/`: the project page
- `demo/`: a copy of the character creator in demo mode. It has no database behind it; everything you create stays in your browser.

The real version, with MariaDB doing the access control, lives in the main repository.
